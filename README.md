IBM API Connect is a comprehensive API management platform that enables organizations to create, secure, manage, share, monetize, and analyze APIs across multiple cloud environments. It offers a robust API gateway, developer portal, lifecycle management, strong governance, built-in security, and flexible deployment options, helping teams accelerate API development and delivery.

**Areas:** API Gateway · API Management · Developer Portal · Developer Tools · IBM

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for IBM API Connect: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
